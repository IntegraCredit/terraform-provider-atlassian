# atlassian_jira_screen_tab_fields (Resource)

Manages the complete, ordered list of fields on a tab of a Jira Cloud screen. This resource is authoritative for the tab: on create and update it removes every field that is not in `fields`, adds the missing ones and moves them into the listed order. Do not use it together with `atlassian_jira_screen_tab_field` on the same tab, or the two resources will undo each other's changes. Destroying it removes every listed field from the tab, which also happens when `screen_id` or `tab_id` changes. To keep the fields on a tab Terraform no longer manages, use a `removed` block with `destroy = false`.

## Example Usage

```terraform
# Owns every field on the tab, in this order. Fields not listed are removed.
# Do not also manage this tab with atlassian_jira_screen_tab_field.
resource "atlassian_jira_screen_tab_fields" "example" {
  screen_id = atlassian_jira_screen.example.id
  tab_id    = atlassian_jira_screen_tab.example.id

  fields = [
    "summary",
    "issuetype",
    "description",
    atlassian_jira_custom_field.example.id,
    "labels",
  ]

  # Destroying this resource removes the listed fields from the tab.
  lifecycle {
    prevent_destroy = true
  }
}

# To stop managing a tab and keep its fields, remove the resource with
# destroy = false instead of deleting the block:
#
# removed {
#   from = atlassian_jira_screen_tab_fields.example
#   lifecycle {
#     destroy = false
#   }
# }
```

## Schema

### Required

- `fields` (List of String) The IDs of the fields on the tab, in display order, for example `summary` or `customfield_10010`. An empty list removes every field from the tab. A field can be on only one tab of a screen.
- `screen_id` (String) The ID of the screen. Changing this forces recreation of the resource.
- `tab_id` (String) The ID of the screen tab. Changing this forces recreation of the resource.

### Read-Only

- `id` (String) The identifier of the resource, in the format `{screen_id}/{tab_id}`.

## Import

Import is supported using the following syntax:

```shell
# Import the fields of a screen tab by {screen_id}/{tab_id}.
terraform import atlassian_jira_screen_tab_fields.example 10000/10001
```
